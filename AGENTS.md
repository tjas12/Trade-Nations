# Trade Nations — project instructions

## Historical fidelity and permanent research guidance

- Our primary objective is to faithfully recreate the original **2010–2013 Trade Nations**.
- Before developing new buildings, level unlocks, resources, shops or graphics, consult [docs/ORIGINAL_GAME_REFERENCES.md](docs/ORIGINAL_GAME_REFERENCES.md).
- Inspect recovered original game data under `original/TradeNations.app/bundle/` before inventing mechanics or unlock requirements. Resolve the files indexed by `Objects.xml`; compare Settings, prerequisites, land variants, recipes and tutorial rules. Imported runtime definitions and balance overrides are not independent historical evidence.
- Prioritize historical accuracy over generic city-builder features. Distinguish version-scoped evidence, unresolved questions and reconstruction decisions.
- Never fabricate original level requirements. Cite the exact source/file, stable ID and game version for numeric claims; mark unknowns as unknown. Do not treat comments or unverified community claims as active original rules.
- Preserve existing working gameplay and save compatibility. Historical corrections require a tested migration plan; never reset towns, delete progress or silently revoke earned unlocks.
- Maintain mobile-first performance and fully offline functionality. Preserve the compact phone UI, touch controls and persistent local saves.
- Keep documentation updated as original mechanics are recovered. Add citations, access/version notes, conflicting evidence and resolved questions to the research library.

This file is repository-root guidance for future Codex sessions and applies throughout the repository. Read and preserve any additional applicable instructions; this section supplements existing guidance.
